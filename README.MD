# Móveis Planejados RS

<img src="/src/img/capa.png" alt="Prévia do site" width="100%">

Site institucional desenvolvido para a empresa **Móveis Planejados RS**, especializada em criar móveis sob medida com qualidade, estilo e funcionalidade.

🔗 Acesse o site: [https://moveisplanejados-rs.com.br](https://moveisplanejados-rs.com.br)

## ✨ Funcionalidades

- Apresentação dos serviços e diferenciais da marca
- Galeria de projetos realizados
- Formulário de contato direto
- Design responsivo e moderno

## 💻 Tecnologias Utilizadas

- HTML5  
- CSS3  
- TailwindCSS  
- JavaScript  
- Google Fonts  
- Ícones via Font Awesome

## 📱 Layout Responsivo

Todo o layout foi construído com **TailwindCSS**, garantindo responsividade e performance em diversos dispositivos, desde celulares até desktops.
